摘要

在 Kleinberg 可导航性模型中，长程边距离分布的幂指数 q 决定仅凭局部信息的贪心路由效率，文献已证明 q=2 是唯一使期望步数为 (log n)² 量级的取值【定理】。本文以数值实验验证该临界机制的成立前提，并量化有限规模下最优指数对 2 的偏离。主要结果有三。其一，q=2 时单步命中概率 P(d) 在整个统计区间（距离 4 至 511，跨度约 128 倍）上介于 0.017 与 0.028 之间，最大与最小之比 1.6，接近常数；同一区间上 q=1、1.5、2.5、3 的比值分别为 59、6.5、11、90，偏离 2 越远，命中机会越依赖距离【实测】。其二，每阶段期望步数与 ln n 成正比：P(d)·ln n 在 n=64 至 1024 间保持在 0.11–0.19，无随规模的系统漂移，与理论值（n=1024 时 0.14–0.15）同水平【实测】。其三，按相对收缩模型推算的总步数在 q=2 时与实测之比为 0.98–1.07，其余 q 散布在 0.78–1.22【实测】。实测最优指数随规模缓慢上移但未达 2：按 0.25 一档的网格读数，n=1024 时 1.5 最优、1.75 次之；对步数曲线作二次拟合，连续极小点从 n=32 的 0.64 移至 n=1024 的 1.61，方向与幅度和已有文献一致【实测】。本文不证明最优性定理，结论不外推至 n>1024。

1 问题与模型

1.1 要回答的问题

现实社会网络呈现小世界现象：网络规模巨大，任意两人之间却只隔少量中间人[14][15]。Milgram 的信件传递实验与后续在线实验进一步表明，这些短路径不仅能被普通人找到，而且找到它们的代价很小[2][3][4]。对这一现象的算法学研究综述见文献[7][16]。

短路径存在，不等于短路径能被找到。在 Watts 与 Strogatz 的小世界模型中，最短路径长度为对数量级[3]；但 Kleinberg 证明，若长程边均匀随机连出，任何只看局部信息的算法都无法在多项式时间内找到它们[1]。Kleinberg 随后在二维网格上加入按距离幂律分布的长程边，证明了尖锐的结论：当且仅当幂指数取临界值 2 时，存在只用局部信息的算法在对数平方步内送达[1]。

这个临界值是渐近意义下的结论。本文关心的是它在可计算的有限规模上如何呈现，具体回答三个问题：

  1. 临界机制的成立前提——各距离尺度上长程边命中率相等——在实测中是否成立；
  2. 每阶段步数正比于 ln n 的推断是否与实测相符；
  3. 有限规模下使平均步数最小的指数取在哪里，随规模如何移动。

1.2 模型定义

要素定义
节点n×n 环面网格，共 n² 个，上下与左右方向相接
距离曼哈顿距离 d(u,v)=|Δx|+|Δy|，其中每个坐标差取环绕意义下的最小值
本地边每个节点与 4 个相邻节点有无向边
长程边每个节点恰有 1 条有向出边，指向 v 的概率与 d(u,v)^(−q) 成正比
信息路由时只知当前节点邻居的坐标与目标的坐标，不知全图

路由规则为严格贪心：每一步在当前节点的 4 个本地邻居与 1 条长程边终点中，选曼哈顿距离最小者；不回退、不搜索、不记忆。本文统一用 q 记幂指数，与课程教材第 20 章一致[13]（原始文献[1]记作 r，交互演示页面记作 α，三者同一量）。

符号表：n 为网格边长；q 为幂指数；d 为两点间曼哈顿距离；T 为贪心路由步数；ℓ 为同图同起终点的最短路长度；P(d) 为距目标 d 的节点单步内将消息送到距目标 d/2 以内的概率；Z(q)=Σ_v d(u,v)^(−q) 为长程边分布的归一化常数。

2 理论依据

2.1 三条界【定理】

Kleinberg[1]对上述模型证明了：

条件结论
q = 2存在分散算法，期望步数 ≤ α₂(log n)²（Theorem 2）
0 ≤ q < 2任意分散算法期望步数 ≥ α_q·n^((2−q)/3)（Theorem 3a）
q > 2任意分散算法期望步数 ≥ α_q·n^((q−2)/(q−1))（Theorem 3b）

常数只依赖维数，不依赖 n。三条界合起来说明 q=2 是唯一使期望步数为 log n 的多项式量级的指数，且偏离任何一侧都要付出 n 的幂次代价。

2.2 命中概率引理

设当前消息持有者为 u，d(u,t)=d。以 t 为中心、d/2 为半径的曼哈顿球是菱形，格点数为 2r²+2r+1（r=d/2 时约 d²/2）。球内任一点 v 到 u 的距离介于 d/2 与 3d/2 之间，故

P(d) = Σ_{d(v,t)<d/2} d(u,v)^(−q) / Z(q) = Θ(d^(2−q) / Z(q))。

归一化常数的三种量级：

情形Z(q)由此 P(d) ≈
q = 2Θ(ln n)Θ(1/ln n)，与 d 无关
q < 2Θ(n^(2−q)/(2−q))∝ d^(2−q)，随 d 增长
q > 2Θ(1)∝ d^(2−q)，随 d 衰减

q=2 的特殊之处在于分子中的 d² 恰被按 d^(−2) 求和抵消，使命中概率在所有尺度上取同一值。这是「平坦性」的来源，也是本文验证的首要对象。

2.3 平坦意味着 (log n)²

将路由过程按距离划分阶段：阶段 j 指距离落在 (2^j, 2^(j+1)] 内，阶段数约为 log₂n。若 P(d) 与 d 无关，则每个阶段内的期望步数为 1/P ≈ c·ln n，总步数约为 log₂n·c·ln n = Θ((log n)²)。直观地说：只要每一跳「距离减半」的机会不随远近变化，消息就像每跳覆盖一个固定比例的剩余尺度，尺度个数只有 log₂n 个，于是总代价是每层代价（∝ ln n）乘以层数（∝ log n）。反之，q<2 时近处的 P 极小，收尾阶段拖长；q>2 时远处的 P 极小，开局拖长。文献[1]中两条多项式下界的直观来源正是这种尺度缺失。

2.4 两个几何修正

其一，环面回绕。当 r 超过 n/2 时，「半径 r 的菱形」在环面上自我重叠，格点计数失效。因此实测一律取 d ≤ n/2。

其二，各向异性。曼哈顿球的形状是菱形而非圆盘：同样相距 d，起点在菱形长轴方向与在对角线方向上，落入球的格点数不同，实测命中率相差约 2 倍（n=1024 时轴向 0.0205，对角方向 0.0419）【实测】。因此理论对照值不取轴向单点，而取对方向分层平均后的期望值。

3 实验设计

3.1 设计立场

本文的实验只做两件事：验证 2.2 节引理的前提（P(d) 在 q=2 时与 d 无关），以及量化有限规模下最优指数对 2 的偏离。最优性本身由 2.1 节定理给出，实验不承担重新证明的任务。

3.2 两组实验

主实验考察增长率与最优指数。n 取 16、32、48、64、80、96、112、128、256、512、1024，q 在全部规模上取 0、0.5、1、1.25、1.5、1.75、2、2.25、2.5、3、4 共 11 档。每个配置默认建 20 张随机图、每图 50 对起终点、共 1000 次路由；n=256 与 512 出于计算量考虑改为 8 张图、共 400 次。记录成功率、平均步数、最短路长、效率比与长程边使用率。

机制实验考察命中概率与逐阶段行为。n 取 64、128、256、512、1024，q 取 1、1.5、2、2.5、3，共 25 个组合；每组合建 5 张图、每图 200 对起终点，共 1000 次路由。对每次路由按初始距离分桶（距离按 2 的幂分桶），记录单步命中是否发生、阶段步数与总步数。

仿真流程（建图—贪心路由—批量统计）与论文图1一致；从给定起点出发的一跳「距离减半」过程与论文图2一致。

3.3 对照口径

实测 P(d) 与理论比较时，理论值按方向分层平均计算，不取轴向单点（理由见 2.4 节）；距离桶按 (2^j, 2^(j+1)] 切分，统计取 j=2 至 8，即 d 在 4 与 511 之间，两端的桶受边界效应影响，不参与量级比较；距离超过 n/2 的样本不计入命中率统计（回绕使球计数失效）。

3.4 可复现性

全部随机数来自显式种子，建图、长程边、起终点各用独立派生流；同一配置在不同运行环境下输出逐位相同。实验程序、结果文件与作图脚本均在项目仓库内，结果可重新生成。

4 结果与讨论

4.1 成功率恒为 1【实测 + 可证】

主实验与机制实验的全部配置中，路由成功率均为 100%，未出现无法前进的节点。这不是测量巧合，而是模型的直接推论：d>0 时，沿朝向目标的较近坐标轴走一格必使距离减 1，故 4 个本地邻居中总存在严格更近者，贪心永不卡死。不同 q 的差别体现在步数，而非能否到达。

4.2 P(d) 在 q=2 时对 d 平坦【实测】

n=1024、q=2 时，统计区间内（距离桶 j=2 至 8，d 从 4 到 511）实测命中率介于 0.0175 与 0.0279，最大与最小之比 1.6，接近常数；方向分层平均的理论值介于 0.0207 与 0.0221（比值 1.1）。同一区间上其他指数的实测范围与变化倍数：

读法：比值越接近 1，命中机会越不挑距离。q<2 时命中率随 d 上升（远处才易命中），q>2 时随 d 下降（近处才易命中），只有 q=2 在整个统计区间内大致持平，且偏离方向与 2.2 节引理一致。实测比值（1.6）略高于理论比值（1.1），差额来自抽样波动与各向异性残差，不改变量级判断。这是临界机制成立前提的直接验证。

4.3 每阶段步数正比于 ln n【实测】

若 4.2 节的平坦性成立，则每阶段步数应正比于 1/P(d) ≈ ln n。直观地说：距离每减半一次要走的步数，应当只随规模的对数增长，而与走到的具体远近关系不大。考察 P(d)·ln n：n 从 64 增至 1024（16 倍），该乘积在各配置的分桶上始终落在 0.11 至 0.19 之间；理论值在 n=1024 时为 0.14 至 0.15，与实测同水平。乘积不随 n 增长，正说明「每阶段步数 ∝ ln n」在实测中兑现。

4.4 总步数可由相对收缩模型预测【实测】

本文用相对收缩模型推算总步数：对当前距离 d，按长程边分布计算每一步的期望相对缩减，据此推算距离每减半一级所需步数，求和得总步数。该模型在 25 个 (n,q) 组合上与实测总步数之比为：q=2 时 0.98–1.07（平均误差 7%）；其余 q 时 0.78–1.22。同一规模内比值随 q 单调下降，穿过 1 的位置随 n 增大向 q=2 移动（n=64 时在 q=1 与 1.5 之间，n=1024 时在 q=2 与 2.5 之间）。误差方向规则且随 q 偏离 2 而增大，可以归因（见 4.7 节），不是抽样噪声。一处偏差值得单独说明：n=1024、q=2 时最远距离桶（d 在 364 附近）的实测命中率比理论低约 15%，本文未找到确凿归因（见 5 节第 4 条）；推算以实测 P(d) 为原料，这一偏差不额外进入误差。

4.7 讨论：谷底为何在 2 左侧【推断】

有限规模下最优指数低于 2，本文归纳四条机制。其一，尺度数量不足：q=2 的收益来自每个距离尺度上都有跳板，尺度数约为 log₂n，n=128 时仅 7 个，长程边有可观比例落在最近一两层、甚至直接落在本地邻居上，等效于浪费。其二，本地边的相对贡献大：距离小时走一格本地边的相对缩减可观，压平了不同 q 之间的差距。其三，环面截断：最大距离为 n/2，q>2 的分布集中于近距离，大尺度上没有可用跳板，这一惩罚随 n 减小来得更早，将最优值向小 q 方向推。其四，菱形各向异性在小 n 上占比更大，对 P(d) 的扰动更明显。四条均为方向性解释，未逐条定量归因。

4.8 讨论：与文献对照【定理】

Clauset 与 Moore[5]在一维环上测得最优指数低于理论值 1，且以 1−A/(log n)² 的形式缓慢逼近（A≈2.85，数值依赖对数底），并指出有限尺寸效应的收敛速度为多对数量级。本文在二维、以 q=2 为目标测到的单调右移与增量递减，形态与之相同；由于维数不同，本文不直接引用其拟合系数。

Martel 与 Nguyen[6]证明了该模型的期望直径为 Θ(log n)，而贪心路由需 Θ(log²n)：短路径的存在性（直径）与可找到性（分散算法）之间有确定的量级鸿沟。本文 4.5 节的数值正是这一鸿沟的呈现：n 从 64 增至 1024（节点数增 256 倍），q=0 的最短路仅从 6.4 缓增至 10.9，平均步数却从 16.2 增至 104.5。

几何变体文献说明临界值 2 不是普适常数：Campuzano 等人[8]在拉伸格子上测得最优指数随几何改变；Roberson 与 ben-Avraham[9]在分形格子上证明最优指数等于分形维数。本文实测的各向异性（2.4 节）属于同类效应的离散表现。相关工作的其他方向包括：无标度网络上的超短导航时间[10]、增强局部感知后的近最优路由[11]，以及同质性生长网络天然形成的可导航性[12]。

5 局限

  1. 规模上限 n=1024。q* 尚未收敛到 2，更大规模的表现属于外推；文献[5]表明收敛速度为多对数量级，接近 2 所需的规模超出可计算范围。
  2. 每节点仅 1 条长程边（k=1）。k>1 时步数下降但机制不变的说法未经本文验证。
  3. 环面与曼哈顿距离是对真实社交空间的高度简化；4.8 节的几何变体文献已表明最优指数随几何改变，故本文数值不宜直接移植到其他度量。
  4. 距离约 364 处（n=1024，最大分桶）实测命中率较理论低约 15%，本文未找到确凿归因，仅记录在案。

6 结论

在 Kleinberg 可导航性模型中，贪心路由成功率恒为 1；q=2 使命中概率在所有距离尺度上取同一值【实测】，从而总步数为 (log n)² 量级；有限规模下最优指数偏低且随规模缓慢上移：按 0.25 档读数，n=1024 时 1.5 最优、1.75 次之，二次拟合的连续极小点为 1.61，均低于 2【实测】。本文不宣称证明了最优性定理——那是文献[1]的结果；不宣称数值结论可外推至更大规模或真实网络。本文验证的是该定理的机制前提在有限规模上成立，并给出偏离的量级与方向。
